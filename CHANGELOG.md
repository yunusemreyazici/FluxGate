# Changelog

All notable changes follow [Keep a Changelog](https://keepachangelog.com/) and this project uses
[Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-08-25

### Added

- Typed Python package and Typer CLI.
- Strict TOML configuration, central path layout, and atomic JSON state.
- Provider capabilities and registry with explicit OpenVPN, sing-box, and Xray placeholders.
- WireGuard enable/disable, key management, deterministic peer allocation, client configuration,
  nftables NAT, systemd lifecycle, forwarding, idempotency, and revocation.
- Safe command execution, dry-run plans, rollback operations, and structured doctor reports.
- Unit tests and GitHub Actions checks for Ruff, mypy, and pytest.
